##Transform natural language into structured Prompt Contracts that make Claude Code deliver on the first try.

CodePromptMaker is your tool for transforming natural language into structured “Prompt Contracts” — well-formatted, optimized prompts designed specifically for Claude Code terminal sessions.

The idea is that you can describe what you want built in plain language, and CPM then converts it into a structured contract that cc can execute efficiently and consistently.

The project is set up as a pnpm monorepo with Turbo and divided into packages: a web frontend, CLI, a runner, a database layer, and shared utilities. The roadmap moves from local usage (v1) to RAG integration (v2), then to SaaS (v3), and finally to cloud-triggered autonomous execution (v4).
