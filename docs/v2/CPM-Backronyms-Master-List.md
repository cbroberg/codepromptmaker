## Usage Guidelines

### Landing Page Hero Animation

Recommended rotation sequence for maximum impact:

```
CPM = Cockpit of the Product Machine
CPM = Create Products Magically
CPM = Code · Prompt · Machine
CPM = Concept-to-Product Machine
CPM = Can't · Pause · Making
CPM = Claude-Powered Manufacturing
CPM = Craft · Polish · Market
```

**Timing**: 3 seconds per expansion, smooth crossfade.

### CLI Spinner Verbs

Action-oriented expansions for `cpm run` and `cpm generate`:

```javascript
export const CPM_SPINNER_VERBS = [
  'Compiling · Pushing · Merging',
  'Configuring · Processing · Monitoring',

  'Crafting · Polishing · Marketing',

];
```
